# USC OIS Assistant (EE542 Lab 9 Part 4)

A private question-answering assistant for USC international students on F-1 status.
It answers only from a curated corpus of USC Office of International Services pages and
federal USCIS / SEVP / CFR documents, cites the passages it used, and says so when the
corpus does not cover a question. Retrieval uses OpenAI embeddings with a FAISS index
rebuilt from MySQL at startup; answers are generated by a local Llama 3.2 3B model
through `llama-server`, and each user's conversation is private to their account.

- Design: [docs/superpowers/specs/2026-10-31-ois-assistant-design.md](docs/superpowers/specs/2026-10-31-ois-assistant-design.md)
- Setup and operator steps: [SETUP.md](SETUP.md)
- Corpus manifest: [data/sources.yaml](data/sources.yaml)

## Layout

```
backend/   FastAPI app (app.py), corpus pipeline (fetch_sources.py, ingest.py), retrieval (rag.py), tests/
frontend/  vanilla HTML/JS/CSS assistant UI
data/      sources.yaml manifest, ois/ (hand-saved PDFs), federal/ (fetched), eval_questions.yaml
sql/       reference schema
```

## Quick Start (Dev)

```bash
# 1) MySQL
mysql -u root < sql/schema.sql

# 2) Backend
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp ../.env.example ../.env   # set JWT_SECRET, OPENAI_API_KEY, LLM_API_KEY

# 3) Corpus
python fetch_sources.py && python ingest.py

# 4) Run (llama-server on :8001, see SETUP.md)
uvicorn app:app --host 0.0.0.0 --port 8000
```

Open http://localhost:8000
